# A place for your notes

This is a disposable sample Base for reviewing the interface. Your own notes stay in your other Usual Base window.

## Working together

Write naturally. Your agents work with the same **plain Markdown files**, and their changes appear here.

- Keep ideas in small notes.
- Organize them into folders.
- Connect a git remote when you're ready to sync.

## A few things to try

- [x] Open a note from the sidebar
- [ ] Switch to Edit in the toolbar
- [ ] Select some words to see the formatting bar

> Use the native sample window to navigate and edit. The browser follows along; select an element there to pause and comment on it.

| Mode | What you see |
| --- | --- |
| View | The rendered document |
| Edit | Markdown source with formatting tools |
